# 项目架构

## 系统架构图

```
┌─────────────────────────────────────────────────┐
│                    浏览器                         │
│    前台 (http://localhost:2368)                   │
│    管理后台 (http://localhost:2368/ghost)          │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│               Ghost 核心服务                      │
│  ┌──────────────────────────────────────────┐   │
│  │            Express Web Server             │   │
│  ├────────────────┬─────────────────────────┤   │
│  │  Content API   │      Admin API          │   │
│  │  (公开只读)    │   (管理员读写)           │   │
│  ├────────────────┴─────────────────────────┤   │
│  │        认证 / 会员 / 评论服务              │   │
│  └──────────────────────────────────────────┘   │
└──────┬───────────────────────┬──────────────────┘
       │                       │
┌──────▼──────┐    ┌──────────▼──────────┐
│ 自定义主题   │    │  SQLite 数据库       │
│ content/    │    │  content/data/      │
│ themes/     │    │  ghost-local.db     │
├─────────────┤    └─────────────────────┘
│ Handlebars  │
│ 模板引擎渲染 │
└─────────────┘
```

## 5 个关键目录

| 目录 | 路径 | 作用 | 可否修改 |
|------|------|------|---------|
| **主题** | `runtime/content/themes/` | Ghost 默认主题 casper 和 source | ✅ 可修改 / 新增 |
| **数据库** | `runtime/content/data/` | SQLite 数据库文件 ghost-local.db | ❌ 不动 |
| **日志** | `runtime/content/logs/` | 运行日志，排错用 | ❌ 不动 |
| **Ghost 核心** | `runtime/versions/6.59.0/core/` | Ghost 核心源码 | ❌ 不动 |
| **配置文件** | `runtime/config.production.json` | 环境配置 | ⚠️ 根据需要改 |

## 修改边界说明

- **允许修改**：主题目录 (`content/themes/`) 下的模板文件
- **允许新增**：`theme/`（自定义主题源码）、`docs/`（文档）、`tests/`（测试）
- **禁止修改**：`versions/6.59.0/core/`（Ghost 核心代码）
- **禁止提交**：`content/data/`（数据库）、`content/logs/`（日志）、`.env`（密钥）

## 请求链路

```
浏览器请求 → 主题模板 (Handlebars) → Content API → Ghost 核心服务 → SQLite 数据库
```

## 上游源码阅读重点

- `runtime/versions/6.59.0/core/` — 核心服务
- `runtime/versions/6.59.0/apps/` — 应用扩展
- `runtime/versions/6.59.0/packages/` — 工具包
